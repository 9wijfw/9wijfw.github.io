Python第二课 --- 安装python

2026-07-28 · 5 分钟阅读
入门 python 编程

前言

经过上一个文章的介绍想必大家都很想学习python了吧(大嘘)，那么在学习之前，我们需要学会如何安装它。
但这时有人问了：不就是装个python吗，有必要搞这么复杂吗？还要出个教程？
这就是你不懂了，装python是个技术活，你装不明白，你就别想用python了
(雷霆笔者依旧贩卖焦虑)

安装

好了，废话少说，让我们来安装python。
第 1步 ，我们打开浏览器(用电脑自带的edge即可)，访问https://www.python.org/(python官网)，你就可以见到如下界面：

找到download的区域（如图）

如果像下载最新版本，点击这个Python3.14.6就可以了（2026/7/31是这个版本，过段时间可能会再变）

那么问题来了，我想下载别的版本（比如3.11,3.6,3.7等等）或者别的系统要下载python怎么办呢？
这个也很简单，看左侧有不同的系统平台或方式可以选，我们就以windows为例，点击它跳转到了一个新页面（网页经过翻译插件翻译，实际页面为英文），这样我们就用了更多选择

以3.13.7为例，这里推荐下载安装版(intaller)配置较为简单，根据自身需求选择点击对应内容

第 2步 在下载完成后打开安装程序(.exe),会见到如下界面



有一个install now和一个 customize installation(一个是默认安装，另一个是自定义安装，如果您不需要更改安装路径之类的可以直接默认安装)
值得注意的是，在最底部有两个有两项一点更要勾选上！！！，尤其是add python to path那个，否则会很麻烦(后文有解决方法)
最后安装完成后点击close关闭程序，为了验证是否成功可以打开cmd


输入python，能正常返回东西即为成功

如果返回不了东西，先看应用列表有没有pthon
(如果没有可以从新跑一遍安装程序)
那么有人又要问了：会不会出现cmd能跑，应用列表也在，但是没法运行代码的情况呢
额…这种情况发生的概率比CRYCHIC复活还要低

(雷霆笔者又在水字数)

补救措施

如果有，那很可能path配置失败或者您没有勾选add python to path。
这时候有人问了：啊，那怎么办？

一失足成千古恨
但也有补救的方法，首先复制您的python安装路径(精确到python根目录文件夹)，然后打开环境变量设置(打开文件资源管理器，对着此电脑右键，选择属性，在弹出的设置界面中点击高级系统设置，在弹出的窗口中选择环境变量)

打开的页面中找到系统变量，下的Path，点击（那一行变蓝色），然后点击编辑，然后点击新建，填入自己的python路径,单击确定（编辑环境变量），确定（环境变量），应用（系统属性）
最后再试着打开cmd输入python，应该就有反应了。

编辑软件推荐

众所周知，写代码时，你怎么能少得了一个牛逼格拉斯的编辑器呢，我推荐使用vscode,微软出品，十分甚至九分好用（大嘘）。
让我们打开它的官网https://code.visualstudio.com/
点击download for windows
打开后如下，选择我同意，下一步

(这里自行选择)

点击安装

到安装结束后打开vscode

在左侧extensions中搜索python，找到这个(发行商是微软的这个)安装

安装完后回到刚打开软件的界面，按住ctrl+shift+P,在弹出的输入框中输入Python: Select Interpreter并选择。

选择你安装过的python即可完成配置
“很多人以为VS Code和Python联动很玄学，其实本质上就是三件事：解释器选对、终端激活、变量加载。只要这三张牌打顺了，剩下的全是畅快体验。”(依旧仙家对话)
