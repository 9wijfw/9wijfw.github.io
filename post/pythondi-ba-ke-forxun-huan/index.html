#for 循环

for循环，它的结构是：
for a in ???:
xxxx
…
可能很多人一上来看到这个就蒙了，别急，让我们来看一个示例程序。

a = 'abcdefg'
for i in a:
    print(i)
print('--- 循环结束 ---')

这是一个很简单的示例程序，从这个程序中我们先看第一行，有一个i，它是什么？
简单的说i只是变量名，循环每次把右边的"下一个值"(就例如这个变量的各个元素)塞给它。它可以是数字、字符串、列表元素——取决于那个可迭代对象每次产出什么,就像这样

for i in range(5):     # i = 0,1,2,3,4  （数值）
for i in [1,2,3]:      # i = 1,2,3      （元素本身）
for i in "abc":        # i = 'a','b','c'（字符）

同时，改 i 不影响下一次迭代（它只是接收者），改 i 不影响原列表（它拿到的是元素值，不是索引，只对不可变元素成立）

#while 循环

while循环，是一个基于布尔值决定是否执行循环的函数，结构如下：

while True: #在while右侧填入布尔值，布尔值为true就循环一次（像这样就是无限循环）
    print('1145141919810')

#让我们再看这个代码
a = 1
while a <= 10:
    print('a太小了')
    a += 1 #这是自增符号，每运行一次a内的值自动加一
print('a大')
